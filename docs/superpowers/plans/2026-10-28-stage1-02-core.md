# S2 core — SQLite 문지기와 로컬 HTTP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** SPEC 5절 테이블, 4절 HTTP 계약, Native host를 만들고 SPEC 8절의 `pytest core/tests` 문장을 모두 참으로 만든다.

**Architecture:** `gateway.py`만 `sqlite3`를 쓴다. 해시·record_id·별칭 해석·병합·SQL 문장 만들기는 DB를 모르는 순수 모듈로
나눠 gateway를 300줄 안에 둔다. `service.py`는 표준 라이브러리 `ThreadingHTTPServer`, `native_host.py`는
`carryover/native/host.py`의 `native_loop` 프레이밍을 그대로 쓴다(옛 `pce` import 줄만 지움).

**Tech Stack:** Python 3.11, sqlite3(3.35+, DROP COLUMN), http.server, pytest, jsonschema(시험 전용).

**Spec:** `docs/SPEC.md` 4·5·6절. 공통 규칙은 `2026-10-28-stage1-00-index.md`.

## Global Constraints
index 파일 그대로. 이 세션은 `core/`와 `.github/workflows/verify.yml`의 pytest 단계만 고친다.
옛 `carryover/native/mvp.py`는 요청 기록·store_version·WAL·RLock·executescript 금지 **패턴만** 본다(DB 구조는 버림).
