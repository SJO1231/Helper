# S7 통합 — e2e:public과 1단계 판정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** `npm run e2e:public`이 공개 나라장터에서 SPEC 8절 e2e 문장을 하나씩 참/거짓으로 판정하고,
네 명령이 모두 통과한 기록으로 1단계를 닫는다.

**Architecture:** 빈 임시 DB로 코어를 띄우고 Playwright Chromium에 빌드한 확장을 올린다. 화면 이동은
`com.gfnOpenMenuMove(menuCangVal)`과 목록 링크 셀 클릭(기존 `scripts/probe/browser-steps.mjs` 도우미 재사용).
판정은 코어 HTTP(`shared/core-client.ts`와 같은 요청 꼴)와 페이지 DOM에서 직접 읽어, 확장이 낸 숫자를 그대로 믿지 않는다.

**Tech Stack:** Node 20, Playwright(내장 Chromium), exceljs(내보낸 파일 읽기).

**Spec:** `docs/SPEC.md` 8절. 공통 규칙은 `2026-10-28-stage1-00-index.md`.

## Global Constraints
index 파일 그대로. 이 세션은 `scripts/e2e-public.mjs`, `scripts/e2e/`, `package.json`의 `e2e:public`,
`docs/company-check.md`만 고친다.
동작 사이 1.5초 이상, 등록·제출·삭제 버튼 금지, 출력·로그에 화면 값(공고번호 등)을 찍지 않는다(수·참/거짓만).
CI에서는 돌리지 않는다.

### Task 1: e2e 틀 (띄우기·배정·보고)

**Files:**
- Create: `scripts/e2e-public.mjs`, `scripts/e2e/setup.mjs`, `scripts/e2e/assign.mjs`, `scripts/e2e/report.mjs`,
  `scripts/e2e/core-http.mjs`
- Modify: `package.json` (`"e2e:public": "node scripts/e2e-public.mjs"`)

**Interfaces:**
- Produces:
  - `startStack(): Promise<{ page, context, extensionId, core: CoreHttp, stop(): Promise<void> }>`
    — 임시 `HELPER_DB`·`HELPER_HOME`, `python -m core.service`, `launchPersistentContext`에 `--load-extension`
  - `assignTestScreens(core): Promise<void>` — `PUT dict_screen`(noupdate 없이)로 아래 배정, `PUT dict_key`로 업무키 표준키
    (`stages`는 그 단계, `as_column 1`)

| 화면 | menu_no | stage | key_fields |
|---|---|---|---|
| 발주계획상세조회 | 01033 | receipt | `["oderPlanNo"]` |
| 입찰공고상세조회(통합) | 01196 | bid | `["bidPbancUntyNo", "bidPbancUntyOrd"]` |
| 사전규격상세조회 | 01141 | contract | `["bfSpecRegNo"]` |

  - `report(name: string, pass: boolean, detail?: object): void` — `{"기준": name, "참": pass, ...수}` 한 줄,
    `finish()`가 거짓이 하나라도 있으면 `process.exit(1)`

- [ ] **Step 1:** 틀을 쓰고 기준 하나(`코어 연결`: `GET /api/tables`가 200)만 넣어 돌린다.
- [ ] **Step 2: Run** `npm run e2e:public` → `{"기준":"코어 연결","참":true}`, 종료 코드 0.
  Native `hello`가 Chromium에서 안 되면(호스트 등록 경로) 여기서 고치고 DECISIONS에 한 줄.
- [ ] **Step 3: Commit** `git commit -m "S7: e2e 틀과 시험 배정"`

### Task 2: SPEC 8절 e2e 문장 일곱 개

**Files:**
- Create: `scripts/e2e/check-collect.mjs`, `scripts/e2e/check-screen-register.mjs`, `scripts/e2e/check-snapshot.mjs`,
  `scripts/e2e/check-remote.mjs`, `scripts/e2e/check-export.mjs`
- Modify: `scripts/e2e-public.mjs` (차례로 부름)

**Interfaces:**
- Consumes: Task 1 `startStack`·`assignTestScreens`·`report`, 확장 리모컨 버튼(Shadow DOM, S3 과제 6의 버튼 글자).

- [ ] **Step 1: `check-collect`** — 상세 3종(발주계획 첫 행 → 01033, 입찰공고목록에서 연계 URL 빈 첫 행 → 01196,
  사전규격 첫 행 → 01141)마다 리모컨 `수집`을 10번(사이 1.5초).
  판정: `g2b_receipt`·`g2b_bid`·`g2b_contract` total이 각 1, `g2b_capture` total이 3.
  거짓이면 detail에 status 분포(new/same/changed/rejected 수)만 남긴다.
- [ ] **Step 2: `check-screen-register`** — 빈 상태의 입찰공고목록(01175)을 열고, 다른 화면에 갔다가 다시 연다.
  판정: `GET /api/tables/dict_screen/records?filter={"menu_no":["01175"]}`의 total이 1.
- [ ] **Step 3: `check-snapshot`** — 발주목록(13713) 검색유형 0001·0002 각각과 입찰공고목록(01175)에서 `스냅샷`.
  판정 ①: 스냅샷 창 그리드 머리글 == 페이지에서 직접 읽은 `getHeaderID(i)`→`getHeaderValue` 목록
  (사전 라벨이 빈 DB라 6절 해석 결과가 화면 L이다). 판정 ②: 스냅샷 전후 모든 테이블 total 합이 같다.
- [ ] **Step 4: 진단 줄** — 위 스냅샷 뒤 리모컨 진단 줄이 `/빈 ref 제외 \d+/`와 `/미등록 키 \d+/`에 맞는다.
- [ ] **Step 5: `check-remote`** — 입찰공고목록에서 보이는 기간 첫 쌍의 시작일 해 Y를 읽고 `−1년`.
  판정 ①: 두 칸이 `(Y−1)0101`·`(Y−1)1231`. 판정 ②: 누른 뒤 3초 동안 `*.do` 요청 0건.
  이어서 조회건수 `100`. 판정 ③: 보이는 그리드의 쪽 크기 select 값이 `100`.
- [ ] **Step 6: `check-export`** — `viewer.html?table=g2b_bid`에서 `CSV`·`Excel`을 눌러 받은 파일을 읽는다.
  판정: 두 파일의 첫 행 == `GET /api/tables/g2b_bid/columns`의 라벨 목록.
- [ ] **Step 7: Run** `npm run e2e:public` → 일곱 기준 + 코어 연결 모두 `"참": true`, 종료 코드 0.
  거짓이 있으면 원인 폴더의 세션(S2·S3·S6)에 넘기고 여기서 그 폴더를 고치지 않는다.
- [ ] **Step 8: Commit** `git commit -m "S7: e2e:public 판정 일곱 개"`

**Files:**

**Interfaces:**
- Consumes: `scripts/install-host.ps1`(S3), `python -m core.seed_load`(seed 과제 3), 리모컨 버튼 글자(S3 과제 6).

- [ ] **Step 1: 세 절만 쓴다.** 40줄 이하, 화면 값은 적지 않는다.
  - 설치: 확장 폴더 올리기, `pwsh -File scripts/install-host.ps1`, `python -m core.seed_load`, 리모컨에 "코어 연결"이 보이는지.
  - 화면 열기: 평소 쓰는 업무 화면을 연다. 진단 줄에 화면이 등록됐다고 보이는지, 같은 화면을 다시 열어도 한 번인지.

  - 파일을 밖으로 내보내는 단계는 넣지 않는다(CSV·Excel 버튼 안내도 빼고, 사전 내보내기 없음).

  `grep -c "^## " docs/company-check.md`가 `3`.
