# S5 shared — 계약 고정 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox (`- [ ]`) syntax.

**Goal:** 확장·뷰어·코어가 같이 보는 타입, JSON 스키마, 코어 클라이언트, 사전 해석 함수를 만들고 `npm run verify`를 세운다.

**Architecture:** `shared/`는 DOM·chrome API를 쓰지 않는 순수 TS. 스키마는 JSON 파일로 두어 pytest도 같은 파일로 검사한다.
사전 해석 규칙은 `shared/fixtures/dictionary-cases.json` 한 벌을 TS·Python이 같이 돈다.

**Tech Stack:** Node 20, TypeScript 5 strict, vitest, ajv 8.

**Spec:** `docs/SPEC.md` 4·6절. 공통 규칙은 `2026-10-28-stage1-00-index.md`의 Global Constraints.

## Global Constraints
index 파일 그대로. 이 세션은 `shared/`, 루트 설정 파일, `extension/common/dictionary.ts`, `.github/workflows/`만 고친다.

    total: number }`, `interface ColumnInfo { id: string; fields: { label: string; type: KeyType; index: boolean } }`
  - `interface DictKey { std_key: string; module: string; stages: string[]; type: KeyType; label: string;
    as_column: 0|1; index: 0|1; derived: 0|1; display: Record<string, unknown> }`
  - `interface DictAlias { site: string; screen_code: string|null; source_key: string; std_key: string }`
  - `interface DictLabel { scope: 'user'|'screen'|'site'|'system'; scope_id: string; key: string; label: string }`
  - `interface DictScreen { site: string; menu_no: string; scrn_no: string; menu_cang_val: string; name: string;

  - `interface Diagnostics { forms: number; grids: number; droppedEmptyRef: number; droppedSameDataList: number;
    failedGrids: number; droppedParam: number; unknownKeys: number; core: 'ok'|'offline' }`
  - `interface ConnectionInfo { baseUrl: string; token: string }`, `const SCHEMA_VERSION = 1`
- Produces: `npm run verify` = `tsc --noEmit && vitest run` (S3가 끝에 `&& node scripts/build.mjs`를 붙인다).

### Task 3: 사전 해석(TS)과 공유 시험표

**Files:**
- Create: `extension/common/dictionary.ts`, `shared/fixtures/dictionary-cases.json`
- Test: `extension/common/dictionary.test.ts`

**Interfaces:**
- Consumes: `DictAlias`, `DictKey`, `DictLabel`.
- Produces:
  - `resolveStdKey(k: string, screenCode: string, aliases: DictAlias[], stdKeys: Set<string>): string | null`
  - `resolveLabel(key: string, screenCode: string, screenL: string, labels: DictLabel[], site?: string): string`
  - `countUnknownKeys(ks: string[], screenCode: string, aliases: DictAlias[], stdKeys: Set<string>): number`
  - `shared/fixtures/dictionary-cases.json`: `{ "aliases": [...], "stdKeys": [...], "labels": [...],
    "stdKeyCases": [{ "k", "screen", "expect" }], "labelCases": [{ "key", "screen", "screenL", "expect" }] }`
    (core 과제 2가 같은 파일을 pytest로 돈다)

- [ ] **Step 1: 시험표를 쓴다.** 값은 자리표시(`keyA`, `dmX.keyA`). 아래 경우가 다 들어가야 한다.
  - 그 화면 alias가 전체 alias보다 먼저: `dmX.keyA` @ `S1` → `stdFromScreen`, @ `S2` → `stdFromGlobal`
  - alias 없고 K가 std_key: `keyB` → `keyB`
  - alias 없고 마지막 `.` 뒤가 std_key: `dmY.keyB` → `keyB`, `param.keyB` → `keyB`
  - 아무것도 없음: `dmZ.nothing` → `null`
  - 라벨: user > screen(scope_id = 화면) > site(`g2b`) > system > 화면 L. 다른 화면의 screen 라벨은 무시.
