# 회사 PC 점검표

사람이 눈으로 보는 것만 적는다. 화면의 값(번호·금액·이름)은 어디에도 옮겨 적지 않는다.
막히면 리모컨 진단 줄의 숫자만 적어 둔다.

## 설치
1. 저장소 폴더에서 `npm ci` 뒤 `node scripts/build.mjs`를 돌린다. `dist/extension` 폴더가 생긴다.
2. 크롬 `chrome://extensions`에서 개발자 모드를 켜고 "압축해제된 확장 프로그램을 로드"로 `dist/extension`을 고른다.
3. 확장 ID가 `igmgbdicnjmipkncpmojbkioialdjkog`인지 본다.
4. PowerShell에서 `pwsh -File scripts/install-host.ps1`을 돌린다. "Registered com.helper.core"가 나오면 된다.
5. 크롬을 모두 닫았다가 다시 연다.

## 화면 열기
1. 평소 쓰는 업무 화면을 연다. 오른쪽 위에 리모컨(수집·스냅샷·−1년·+1년·조회건수·뷰어)이 보이는지.
2. `스냅샷`을 한 번 누른다. 진단 줄 끝이 "코어 연결"인지(코어 꺼짐이면 설치 4번을 다시).
3. 처음 연 화면이면 진단 줄의 "새로 등록한 화면" 수가 1 늘었는지.
4. 같은 화면을 다시 열고 스냅샷을 누른다. "새로 등록한 화면" 수가 그대로인지.
5. 단계가 정해지지 않은 화면은 `수집` 버튼이 꺼져 있는 것이 정상이다.

## 버튼
1. `스냅샷`: 표가 뜨고 열 머리가 사람이 읽는 이름인지. 닫기로 닫힌다.
2. `수집`(단계가 정해진 화면에서만): "새로 저장함" 또는 "바뀐 칸 n개" 알림이 뜨는지.
   같은 화면에서 다시 누르면 "바뀐 것 없음"인지.
3. `뷰어`: 새 탭에 표가 뜨고 위에 행 수가 보이는지. 칸을 눌러도 고쳐지지 않는(읽기 전용) 것이 정상이다.
4. 목록 화면의 `−1년`: 기간 두 칸이 앞 해 1월 1일~12월 31일로 바뀌고, 조회는 직접 눌러야 하는지.
5. 목록 화면의 조회건수 `100`: 목록 아래 쪽 크기가 100으로 바뀌는지.
6. 안 되는 버튼이 있으면 진단 줄의 숫자(폼·그리드·빈 ref 제외·미등록 키)와 버튼 이름만 적는다.
