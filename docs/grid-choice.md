## 읽는 법과 한계
- **16ms 기준**: 빈 페이지(대조군)도 프레임 간격 90번째 백분위가 16.7ms이고 ≤16ms 비율은 0%다. 60Hz에서는 한 프레임이
  16.7ms라 문장 그대로는 어떤 것도 통과할 수 없다. 그래서 ≤17ms로 표를 냈고, SPEC 191줄을 16.7ms로 고쳤다.
- **정렬 시간**은 코어 왕복(HTTP·SQLite)을 뺀 값이다. 자료 공급 함수가 메모리에서 정렬한다. 필터는 같은 길(`setFilter` → 다시 요청)이라 따로 재지 않았다. 둘 다 S6 bench가 코어 포함으로 다시 잰다.
- **첫 화면**은 이동 시작부터 첫 행 글자가 DOM에 생길 때까지다(그려진 프레임이 아님).
- 이 컨테이너는 GPU가 없어 실제 PC와 절대값이 다르다. 라이브러리끼리 비교로만 읽는다.
- RevoGrid가 쓰는 `@stencil/core`는 RevoGrid의 의존성에 없어 따로 설치해야 번들이 된다.
- 우클릭 메뉴 "없음"은 실제 우클릭 뒤 메뉴 요소가 안 생긴 것과 위 근거로 판단했다. Community 문서를 따로 읽지는 않았다.
- RevoGrid는 정렬을 가로채 다시 받아 넣는 방식이라 1만 행 정렬이 171ms로 느는데, 쪽 공급이 Pro라 어쩔 수 없다.
